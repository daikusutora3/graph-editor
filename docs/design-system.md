# デザインシステム

画面の見た目は、`app/globals.css` のトークンと `components/ui` のレシピで決めます。機能のコードは、それを組み合わせるだけにします。新しい見た目が必要になったら、まずここにレシピを足してから使います。個別の部品の使い方は [UIコンポーネント](ui-components.md) を参照してください。

`tests/verification/design-system.ts` が、`app`・`components/content`・`features/graph-editor/{ui,canvas,shell}` を対象に、下のルールを守っているかを検査します。

## 作る前に

1. **似ている既存の画面を探す。** 読み込みなら書き出し、メニューなら右クリックメニューのように、同じ役割の画面の構成をそのまま使う。新しい構成を作るのは、どの既存画面にも当てはまらないときだけにする。
2. **置き場所でレシピを選ぶ。** 見た目の好みではなく「キャンバスに浮かぶのか」「パネルの中にあるのか」で決める（下の表）。
3. **ライトとダーク、デスクトップと320px幅で見る。** ブラウザで実際の画面を確認してから終える。
4. **`bun run test` を通す。** 契約違反は、ファイルと行番号、代わりに使うレシピと一緒に表示される。

## 色のトークン

| 用途             | トークン                                                      | 使いどころ                                            |
| ---------------- | ------------------------------------------------------------- | ----------------------------------------------------- |
| 画面の地         | `--bg`                                                        | ページとキャンバス、くぼんだ表示面                    |
| 面               | `--panel-solid` / `--panel`                                   | カード・入力欄 / 浮かぶ面（半透明）                   |
| 塗り             | `--fill` / `--fill-2`                                         | ホバー、セグメントの溝、チップ                        |
| 区切り           | `--hair` / `--line`                                           | 面の中の細い区切り / カードや表示面の枠               |
| 操作の境界       | `--control-border`                                            | 入力欄・枠付きボタン。3:1を満たす最も淡い値にしてある |
| 選択・フォーカス | `--control-accent` / `--focus`                                | 選択中の枠 / フォーカスの輪郭                         |
| 文字             | `--text` / `--text-2` / `--muted`                             | 本文 / 操作の文字 / 補足・ラベル                      |
| 強調と状態       | `--primary` `--accent*` `--danger*` `--success*` `--warning*` | 主操作、選択中、削除、完了、注意                      |

- Tailwindの色名（`bg-white`、`text-gray-500` など）や16進数を直接書かない。
- 枠は3段階だけ使う。面の中の区切りは `--hair`、カードや表示面は `--line`、入力欄・選択欄・チェックボックスだけ `--control-border` にする。ボタンには枠を付けず、塗りで区別する（文字で操作だと分かるため）。
- `--control-border` を淡くしたいときは、`tests/verification/design-contrast.ts` の3:1を満たす範囲で `globals.css` の値を変える。部品ごとに薄い色へ置き換えない。

## 面（`surface`）

| レシピ              | 置き場所                                                 | 例                                         |
| ------------------- | -------------------------------------------------------- | ------------------------------------------ |
| `surface.floating`  | キャンバスの上に浮かぶもの（`ge-panel`、半透明＋ぼかし） | ツールバー、ポップオーバー、通知、トースト |
| `surface.card`      | ページ・パネル・空のキャンバスに並ぶカード               | サンプルカード、開始カード、目次           |
| `surface.inset`     | パネルの中のくぼんだ表示面                               | コード、プレビュー、確認ボックス           |
| `menuStyle.surface` | 浮かぶメニュー（項目は `<ActionRow density="menu">`）    | 右クリック、範囲選択、言語メニュー         |
| `fieldSurface`      | 入力欄・選択欄・検索欄                                   | `Select`、`TextInput`、テキスト欄          |

- 影は使わない。面どうしは `--line` の枠と地の色の差で分ける。
- `backdrop-blur-*` は書かない。ぼかしは `ge-panel` が持つ。

## ボタン

ボタンはすべて枠なしで、塗りの強さで役割を表します。1つの画面に `primary` は1つまでにします。

| `variant`             | 見た目                     | 使いどころ                                   |
| --------------------- | -------------------------- | -------------------------------------------- |
| `primary`             | 濃い塗り                   | その画面の主操作（反映、コピー）             |
| `secondary`           | 淡い塗り（`--fill`）       | それ以外の操作（保存、ファイルを開く、作成） |
| `choice`              | 淡い塗り、選択中は青       | 並べた選択肢（配置の種類）                   |
| `ghost`               | 塗りなし、ホバーで淡い塗り | ツールバー・バー・行の中の操作               |
| `danger`              | 淡い赤の塗り               | 確認後の削除などの破壊的な操作               |
| `danger-ghost`        | 赤い文字、塗りなし         | ツールバーやバーの中の削除                   |
| `success` / `warning` | 状態の塗り                 | 操作の結果（コピー済み、コピーできない）     |

| 部品            | 使いどころ                                                         |
| --------------- | ------------------------------------------------------------------ |
| `Button`        | 文字のあるボタン                                                   |
| `IconButton`    | アイコンだけのボタン（`xs` は入力欄の中のクリアなど）              |
| `LinkButton`    | ボタンと同じ見た目のリンク                                         |
| `ActionRow`     | メニュー項目、パネル内の行操作（ボタンまたはリンク）               |
| `Segment`       | 排他的な選択肢。スライダーのプリセットも同じ `segmentItem` を使う  |
| `buttonClass()` | `<summary>` など、要素を変えられないものをボタンと同じ見た目にする |

- 主操作と小さなメニューを組み合わせるときは、両方を `splitGroup(active)` で包み、主操作に `splitStart`、メニューの開閉に `splitEnd(active)` を付ける。ホバーと選択中の塗りは2つまとめて付き、選択中だけ境目に細い線が入る。
- モバイルのバーでは、ボタンを `layout="stacked"`（アイコンの下に12pxのラベル）にそろえる。タッチ操作ではツールチップが出ないため、ラベルを省かない。

`features/` の中で `<button>` や `<a>` を直接書くと `design-system` テストが失敗します。キャンバスの当たり判定や色見本など、ボタンの見た目を持たない例外は、テストの `allowed` に理由と一緒に登録します。

## 寸法

| 項目       | 値                                                                                                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 角丸       | `rounded-bar`（14px：浮動バー）、`rounded-xl`（12px：パネル・カード・メニュー）、`rounded-lg`（8px：操作・表示面・メニュー項目）、`rounded-md`（6px：小さなチップ） |
| 入れ子     | 外側の角丸 − 内側の余白 ≒ 内側の角丸（例：`rounded-xl p-1.5` の中は `rounded-lg`）                                                                                  |
| 操作の高さ | 32px（`sm`）、36px（`md`）、40px（`lg`）。タッチでは44px以上                                                                                                        |
| 浮動バー   | 高さ `min-h-bar`（54px）、角丸 `rounded-bar`                                                                                                                        |
| 文字       | `text-meta`（11px）、`text-xs`（12px）、`text-control`（13px）、`text-sm`（14px）以上                                                                               |

角丸と文字サイズに任意値（`rounded-[14px]`、`text-[13px]`）は書かない。

## 文字の役割

| レシピ           | 用途                                                                |
| ---------------- | ------------------------------------------------------------------- |
| `fieldLabel`     | 入力・選択肢・スライダーの見出し（`ControlRow` と `Slider` が使用） |
| `SectionLabel`   | 複数の行をまとめるグループ見出し                                    |
| `textStyle.note` | 操作の下や横に置く補足文                                            |
| `textStyle.meta` | 件数や状態などの等幅の小さな表示（`N=6 M=5`、`79/79`）              |

## 例外

例外は `tests/verification/design-system.ts` の `allowed` に、理由のコメントと一緒に追加します。現在の例外は、ガイドのPNGプレビューの白背景（書き出し結果を示すため）、開始カードの挿絵、モバイルのシートの角丸です。
