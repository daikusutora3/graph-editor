# UIコンポーネント

操作UIの共通部品は `components/ui/controls.ts` から使います。グラフの状態や翻訳は呼び出し側で扱い、共通部品は機能に依存させません。

| 部品                              | 用途                                                                                                             |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `Button` / `IconButton`           | 通常の操作、アイコンだけの操作                                                                                   |
| `ChoiceButton`                    | 配置や書き出し用途などの選択・実行ボタン。`layout="tile"` でアイコン・名前・補足を縦に並べる                     |
| `Segment`                         | 相互に排他的な選択。選択状態、チェックマーク、矢印キー、Home/End、1つのTab停止点を管理する                       |
| `OptionToggle`                    | 真偽の設定。行全体が操作対象で、右端のチェックボックスに状態を示す                                               |
| `Select` / `TextInput` / `Slider` | ネイティブ入力、選択、数値の調整                                                                                 |
| `ControlGroup`                    | パネル内の見出しと項目間の余白。連続するチェック行は `spacing="tight"`                                           |
| `ControlRow`                      | 短い見出しを左、操作を右に並べる。長い見出しは `layout="stacked"`。単一の入力には `htmlFor` と入力の `id` を結ぶ |
| `ActionRow`                       | メニューや設定内の行操作。削除は `tone="danger"`、確認待ちは `active`、補足は `trailing`                         |
| `PanelActions`                    | パネル下部の操作を等幅で並べる。子の `Button` は `wrap` を指定する                                               |

## 見た目の変更場所

- 色・面・文字色は `app/globals.css` の意味別トークンを使う。明暗テーマごとの色を各パネルに書かない。
- 操作のフォーカス、面、アイコンの線幅は `components/ui/control-styles.ts` で管理する。Lucideの線幅は1.75、サイズは使用場所に合わせる。ブランド画像は固有の形を維持する。
- ボタンのサイズ・選択状態・無効状態は共通部品のプロパティで指定する。`className` は配置に使い、各パネルで枠・背景・線幅を上書きしない。
- 通常のツールバーは一行を維持し、パネルの長い操作は `Button wrap` を使う。長い選択肢は `Segment wrap` を使う。スマホの操作領域は44px以上を保つ。
- パネルの外枠、閉じる操作、フォーカス移動、スクロールは既存の `EditorPanelShell` で管理する。パネルごとに作り直さない。
- パネルの外を押すと閉じる。パネル内の操作は維持し、表示ボタンによる開閉や別パネルへの切り替えはボタン側で管理する。閉じるボタンとEscも共通で使える。
- tooltipは `data-tooltip` と `data-tooltip-side` で指定し、`TooltipLayer` が画面内に配置する。上下の余裕に応じて表示側を切り替え、左右は画面端から8px以上空ける。パネルごとに表示処理を追加しない。

設定・PNG・書き出し・配置・読み込み・アプリメニューに共通部品を適用しています。ツールバー、選択パネル、サンプル一覧も同じ操作部品を使います。ガイドの本文用部品（`ContentSection`、`Card`、`Callout`など）も `components/ui` に置き、同じ色トークンを使います。

## 確認

`node scripts/toolchain.mjs run check` に加え、in-app browserで320px幅の長い翻訳、短い画面のスクロール、明暗テーマ、選択肢の矢印操作、ラベルを押したときの入力フォーカス、閉じて開き直したときのフォーカスを確認します。レイアウトの変更はグラフのデータ処理や保存処理から分けて扱います。
