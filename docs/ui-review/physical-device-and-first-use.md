# Safari・初見利用の確認

実施日：2026-10-06。対象はこの作業ツリーの本番ビルドです。
実Safariによる検証と専門家による初見向け操作レビューを実施しました。参加者による観察とは区別します。

## 検証環境

ローカル本番配信：`http://127.0.0.1:3323`。
公開サイトには今回の変更が反映されていないため、公開サイトでの確認と混同しません。

実Safari 26.6、macOS 26.6.1（25G76）、専用WebDriverセッションを使用しました。
日本語・英語・簡体字中国語、幅600 / 960 / 1440px、明暗テーマの18条件です。
実際のviewport寸法は結果JSONへ記録しています。リロードの復元は同じセッション内で確認しました。

## 初めて使う参加者に渡す課題

参加者にはボタン名、モード名、形式名、正解の手順を先に説明しません。
観察者は詰まった時点の状況を記録し、本人が助けを求めるまで操作を代わりに行いません。
途中で説明した場合は、その課題を「説明後に完了」と記録します。

1. このアプリで、頂点が5つある輪の図を作ってください。
2. 頂点を1つ選び、色を変えて、別の場所に動かしてください。
3. 作った図を、あとから同じ配置・色で編集できるファイルとして保存してください。
4. 作った図を、資料に貼れる画像として保存してください。
5. ページを再読み込みし、続きの編集ができるか確かめてください。
6. 次のデータから図を作ってください。

   ```text
   4 4
   1 2
   2 3
   2 4
   3 4
   ```

観察者は各課題の開始・終了時刻、最初に選んだ操作、迷った場所、戻り操作、
援助の有無、本人の発言を記録します。完了後に「一番迷ったところ」と
「保存したファイルを何に使えると思ったか」を本人の言葉で聞きます。
所要時間だけで良し悪しを決めず、図の完成・保存内容・操作の理解も確認します。
参加者のグラフの知識とアプリの利用経験を別々に記録します。

## Safariでの確認

実際に確認した操作は、Enterで読み込みパネルを開く、Tab移動、Escapeで閉じる・開始ボタンへのフォーカス復帰、
開いてすぐの複数行入力、4頂点・4辺の作成、頂点選択、緑への変更、ドラッグによる移動、
再編集用JSONの出力内容、PNGプレビュー、再読み込み後の色・配置の保持です。
書き出しパネルとツールバーのボタンが画面内に収まることも確認し、18条件すべて合格しました。
Safariのネイティブダウンロード操作は未検証です。生成JSONはテスト実行側で保存しました。
JSONファイルとPNGファイルのアプリからのダウンロードは、下記のChromium操作レビューで確認しました。

2026-10-06にローカルUI検証の限定例外とリモートオートメーションの有効化が承認されました。
OS認証後、実Safariのセッションを作成してテストを実行できました。
一度限りのGUI設定操作のhook許可は除去済みです。GitHub Issuesの禁止事項は維持しています。

## 検出して修正した不具合

Safariで読み込みパネルを開き、すぐデータを入力すると、先頭の「4」の入力後に
形式選択へフォーカスが移り、残りの入力が失われました。イベント記録で再現を確認しました。
原因はパネル表示後30msの初期フォーカス処理です。既にパネル内の操作対象へ
フォーカスがある場合は、その対象を維持するよう修正しました。
Chromiumの回帰テストでは初期フォーカス処理を意図的に遅らせ、入力を中断しないこと、
Escapeでのフォーカス復帰、キーボードで開く動作が保たれることを確認しました。

## 初見向け操作レビューで改善した点

頂点を選ぶと色やラベルを編集できることが、狭い画面では案内されていませんでした。
3言語で説明を追加し、狭い画面でも折り返して表示するようにしました。
書き出し用途の選択ボタンには `aria-pressed` を追加し、選択中の用途を読み上げでも判別できます。
これは専門家の操作レビューに基づく判断です。初見参加者の迷いや発言を観測した結果ではありません。

## 専門家による操作レビューの結果（2026-10-06）

初見の参加者を使った検証ではありません。専用のChromiumセッションで、課題を操作した結果です。

| 課題           | 確認できた結果                                                        |
| -------------- | --------------------------------------------------------------------- |
| 5頂点の輪      | Cycleの頂点数を5へ変更し、5頂点のグラフを作成                         |
| 色・位置の編集 | 頂点を緑へ変更し、ドラッグで位置を変更。保存状態へ反映                |
| 再編集用に保存 | JSON形式を選び、アプリの保存ボタンから実ファイルをダウンロード        |
| 画像にする     | PNG画面へ進み、保存ボタンから実ファイルをダウンロード。画像も目視確認 |
| 再読み込み     | 編集した色と位置が保存され、同じウィンドウで再読み込み後に保持        |
| JSONの入力     | ファイル選択で保存したJSONを読み込み、反映                            |
| データの入力   | 4頂点・4辺のデータを入力し、4頂点のグラフを作成                       |

上記の操作中、ページ例外は検出されませんでした。保存したPNGで緑の頂点が描画されることも確認しました。
これだけでは、初めて使う人が用途を理解できるか、どこで迷うかは判断できません。
参加者の完了時間・迷い・発言は取得していません。
